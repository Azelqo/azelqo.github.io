# MANABIXX Media

MANABIXXが運営する、勉強・受験・進路の教育メディアです。

- 勉強モチベーション
- 学習法・受験対策
- 高校特集
- 高専特集
- 大学・学部特集

## 技術構成

- Hugo
- Hugo Theme Dream
- Markdownによる記事管理
- GitHub Actions / GitHub Pages

## ローカルプレビュー

```bash
hugo server -D
```

## 記事の追加

`content/posts/` にMarkdownファイルを追加します。公開する記事はフロントマターで `draft: false` にするか、draftを省略します。

記事には公開日時を含めてください。日時は日本時間（+09:00）で管理します。

## 運営方針

MANABIXX Studyとは独立したメディアとして運営します。学校・大学・入試制度などの変動情報は、公式情報で確認できる範囲を明記します。
