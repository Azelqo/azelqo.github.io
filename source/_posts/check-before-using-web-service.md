新しいWebサービスを見つけると、まず画面の使いやすさや機能を試したくなります。ただ、使い始めてから「データを外へ出せない」「無料だと思っていた機能が有料だった」「アカウントを消す方法が分からない」と気づくこともあります。

試す前に、機能以外の条件も一度確認しておくと、あとで困りにくくなります。

![Webサービスを試す前に確認したい6つの項目](/images/service-checklist.svg)

## 1. 何を解決するために使うのか

最初に、サービス名ではなく用途を書きます。

- メモを保存したい
- 複数端末で同じファイルを使いたい
- チームで作業を共有したい
- データを検索・整理したい

目的が曖昧なまま登録すると、機能が多いサービスほど設定に時間を使いがちです。必要な機能を2〜3個に絞ってから比較します。

## 2. データを取り出せるか

重要なメモやファイルを保存するなら、サービスを使わなくなったときにデータを取り出せるか確認します。

- Markdown、CSV、PDFなど、どの形式で書き出せるか
- 一括で書き出せるか、1件ずつなのか
- 添付ファイルや画像も含まれるか
- 書き出したデータを別のアプリで開けるか

「エクスポート対応」と書かれていても、必要なデータがすべて含まれるとは限りません。少量のテストデータで実際に試すのが確実です。

## 3. 無料プランと有料プランの境界

料金ページでは、月額だけでなく次の条件も確認します。

- 無料で使える期間に制限があるか
- 保存容量や登録件数に上限があるか
- 一部の機能だけ有料なのか
- 年払い・自動更新の条件はどうなっているか
- 解約後にデータを閲覧・取得できるか

無料プランがあることと、必要な使い方を無料で続けられることは同じではありません。

## 4. どの情報を預けることになるか

登録時に求められる情報と、サービスに保存する内容を確認します。

- メールアドレスなどのアカウント情報
- アップロードするファイルや画像
- 共有リンクを知っている人が見られる情報
- 他のサービスと連携したときに渡る情報

必要以上の個人情報や、公開したくない内容を最初から登録しないことも大切です。プライバシーポリシーでは、収集する情報、利用目的、第三者提供、削除方法を確認します。

## 5. 使う端末・環境に対応しているか

パソコンで使いやすくても、スマートフォンでは操作しづらい場合があります。

- 普段使うブラウザーで動くか
- スマートフォンでも主要操作ができるか
- オフラインでも使える機能があるか
- データを同期するタイミングを選べるか
- アクセシビリティやキーボード操作に問題がないか

毎日使う予定なら、登録前にスマートフォンでも主要画面を確認しておくと安心です。

## 6. アカウントを守る方法があるか

ログイン方法、二段階認証、パスキー、アカウント復旧の方法を確認します。特に、重要なデータを預けるサービスでは、パスワードを忘れた場合や端末を失った場合にどう復旧できるかも重要です。

他のサービスと同じパスワードを使い回さず、利用できる場合は多要素認証を設定します。

## 7. 使わなくなったときの終了方法

始める前に、退会やデータ削除の方法も確認します。

- アカウント削除の手順が公開されているか
- 削除前にデータを書き出せるか
- 共有リンクや連携アプリを停止できるか
- 削除後にデータがどう扱われるか

「始めやすさ」だけでなく「やめやすさ」も、サービスを選ぶときの条件です。

## 迷ったときの短いチェックリスト

| 確認項目 | 判断すること |
|---|---|
| 目的 | 必要な機能がそろっているか |
| データ | 自分で書き出せるか |
| 料金 | 無料・有料の境界が明確か |
| プライバシー | 何を預けるのか理解できたか |
| 環境 | 普段使う端末で問題なく動くか |
| セキュリティ | 安全なログイン・復旧方法があるか |
| 終了方法 | データを持ち出して退会できるか |

すべてを完璧に調べる必要はありません。まずはデータの書き出し、料金、プライバシー、終了方法の4点を確認するだけでも、使い始めてからの想定外を減らせます。
